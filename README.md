# 王様のスプーン｜在庫フォーム

バイト向けの在庫入力・LINE共有Webアプリです。

## 使い方

1. `index.html` をスマホのブラウザで開く（または GitHub Pages で公開）
2. ＋／− ボタンで数量を入力（数字タップで直接入力も可）
3. **コピー** でクリップボードにコピー、または **LINE共有** でLINEに直接送る

入力内容は端末のブラウザに自動保存されます（翌日も前回の値が残ります）。

画面下部には肉発注・野菜発注・油回収・仕込みマニュアルへのリンクがあります。

## ローカルで確認

```bash
cd "/Users/apple/Desktop/王様のスプーン　在庫フォーム"
python3 -m http.server 8080
```

ブラウザで http://localhost:8080 を開いてください。

## ファイル

- `index.html` — 画面
- `styles.css` — デザイン（スマホ最適化）
- `app.js` — フォーム・コピー・LINE共有
- `staff-manual.pdf` — 仕込みマニュアル
