コピー・LINE共有で送った内容は王様一集計に溜まります。

  • 在庫レポート … 共有テキスト全文
王様一集計を開く
在庫・備考をリセット

すべての在庫・発注を0にし、仕込み・備考・タイミー評価を空にします。日付はそのまま残ります。

このアプリの使い方

1. 日付を確認する

画面上部の日付が報告日になっているか確認してください。間違っていたらタップして変更できます。

2. 数量を入力する

各項目の＋／−ボタンで数量を変更します。数字をタップすれば、キーボードから直接入力もできます。

  • 0 … 数量をリセット
  • 0.1 … 具材など、半分単位で増減（±0.1）
  • 在庫／発注 … お肉・具材は左が在庫、右が発注です

3. 本日の仕込みとタイミー評価

本日の仕込みは送信前に必須です。仕込みがない日は仕込みなし、ある日は該当タブをタップしてください（仕込みなしと他の項目は同時に選べません）。

ルーストックやスープ具材が少ないと、明日の仕込み推奨が自動で表示され、共有文にも載ります。

タイミー評価で「良い」「悪い」を選びます。同じボタンをもう一度押すと選択を解除できます。

その下の備考欄に、伝えたいことがあれば自由にコメントを書いてください。

4. 送信する

入力が終わったら、画面下のボタンから共有します。

  • プレビュー … 送信前に内容を確認
  • コピー … テキストをコピー（LINEなどに貼り付け）
  • LINE共有 … LINEを開いてそのまま送る
  • コピー・LINE共有時に、店舗のスプレッドシートへも自動で送信されます

5. その他

  • 入力内容は自動保存されます（ブラウザを閉じても残ります）
  • クイックリンクから肉発注・野菜発注・油回収・タイミーQR・タイムカード・仕込みマニュアルを開けます
  • スプレッドシートを確認から、店舗の集計シートを開けます
  • 在庫・備考をリセットから、すべて0表示に戻せます

6. ホーム画面に追加する

よく使う場合は、ホーム画面に追加しておくとアプリのようにすぐ開けます。

iPhone（Safari）

  1. Safariでこのページを開く
  2. 画面下の共有ボタン（□に↑）をタップ
  3. ホーム画面に追加を選ぶ
  4. 追加をタップ

Android（Chrome）

  1. Chromeでこのページを開く
  2. 右上の⋮（メニュー）をタップ
  3. ホーム画面に追加またはアプリをインストールを選ぶ
  4. 追加をタップ
